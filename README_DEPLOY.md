## Railway Variables

Оставь уже существующие переменные и добавь/проверь:

```env
BOT_TOKEN=...
DATABASE_URL=...
PANEL_URL=https://...
PANEL_API_TOKEN=...
# либо PANEL_LOGIN + PANEL_PASSWORD

DA_URL=https://www.donationalerts.com/r/...
DA_TOKEN=...

SUB_DOMAIN=https://moonlight-vpn.ru
INBOUND_IDS=1,2,3,4,5
```

`INBOUND_IDS` — ID всех inbound'ов, которые должны появиться у покупателя в одной подписке.

Если оставить старую переменную `INBOUND_ID`, код тоже запустится, но будет только один inbound.

## Как назвать страны в 3X-UI

В 3X-UI у каждого inbound задай понятный **Remark**, например:

- `🇩🇪 Германия`
- `🇳🇱 Нидерланды`
- `🇸🇪 Швеция`
- `🇮🇹 Италия`
- `🇪🇪 Эстония`
- `🇵🇱 Польша`
- `🇨🇭 Швейцария`

В настройках Subscription / Share links поставь шаблон remark:

```text
{{INBOUND}}
```

Тогда в Happ/v2rayTun и других клиентах страна будет называться по remark inbound'а. Конкретный клиент сам решает, показывать ли ниже протокол/transport отдельной строкой.
